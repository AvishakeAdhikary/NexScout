# ADR-0001: Technology stack and pinned versions

- **Status:** Accepted
- **Date:** 2026-10-16

## Context
The spec (§12) recommends Next.js, FastAPI, LangGraph, PostgreSQL, Playwright and Electron. Versions
were checked against the PyPI and npm registries on 2026-10-16. The host has Python 3.14.8, which is
newer than the release several native-wheel dependencies were primarily tested against.

## Decision
**Python runtime: 3.13** (installed by uv. The host interpreter is never used). All selected packages
declare `requires-python >= 3.10/3.11`, so 3.13 is well inside the supported range. Moving to 3.14 is a
later, separately tested change.

this table, are authoritative.

## Alternatives considered
- **Python 3.14:** viable on paper, but deferred to avoid wheel and compatibility surprises in the
  native stack (psycopg-binary, pydantic-core, cryptography, greenlet).
- **pnpm:** not installed. npm workspaces are sufficient.

## Consequences
- `uv python install 3.13` is required on new machines (documented in DEVELOPMENT.md).
- Version-sensitive APIs (LangGraph checkpointer, MCP 2.x, a2a-sdk 1.x) are verified against
  the installed package source/docs when their milestone begins, not assumed.

## Addendum 2026-10-16 (M1 implementation)
- Next.js scaffolded at **16.4.2** with TypeScript 5.x (create-next-app default). TS 7 is not adopted.
  `cacheComponents` is on: client components that read route params or search params sit inside `<Suspense>`.
- **Contracts** live in `apps/web/src/lib/api/` (generated by `scripts/gen-contracts.sh`), not in a
  separate `packages/contracts` workspace. Extract them into a package when the Electron app (M9)
  needs to share them.
- shadcn/ui 4.21.5 (`base-nova` style, Base UI primitives) depends on the npm package **`cn`**
  (0.4.0, published by `shadcn`, repo `shadcn-ui/cn`) in place of clsx + tailwind-merge. Reviewed on
  2026-10-16: no install scripts, no runtime dependencies, no network or child-process use in
  `dist/` or `bin/`. Accepted.
- `@types/node` raised to ^24 (Vitest 5 peer requirement). Docker and CI use Node 24 LTS.
- Python `uuid.uuid7` exists only in 3.14+, so `infrastructure/db/base.py:new_id` is a local
  RFC 9562 implementation.
